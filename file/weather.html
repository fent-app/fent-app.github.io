1引言

Shuoweb（以下简称"我们"）致力于保护您的隐私。本隐私政策适用于我们提供的所有网站、应用程序及服务（统称"我们的服务"）。

请您在使用我们的服务之前，仔细阅读并充分理解本政策的全部内容。一旦您开始使用我们的服务，即表示您已同意本隐私政策所述的信息收集和使用方式。

本政策将帮助您了解：我们收集哪些信息、如何使用这些信息、您对信息享有哪些权利，以及我们如何保护您的信息安全。

2我们收集的信息

2.1 您主动提供的信息

  • 账户信息：当您注册账户时，我们可能收集您的用户名、邮箱地址和密码（加密存储）。
  • 自定义内容：您在服务中主动输入的自定义城市、偏好设置等数据。
  • 反馈与沟通：您通过邮件、表单等方式向我们提交的反馈、建议或问题描述。

2.2 自动收集的信息

  • 设备信息：设备型号、操作系统版本、浏览器类型、屏幕分辨率等。
  • 位置信息：经纬度坐标（仅在您授权后获取），用于提供基于位置的服务如天气查询。我们也可能使用 IP 地址进行粗略定位。
  • 使用数据：访问时间、访问页面、停留时长、点击行为等日志信息。
  • IP 地址：用于网络通信、安全防护及粗略地理定位。

2.3 信息收集汇总表

信息类型 收集内容 收集方式
账户信息 用户名、邮箱 用户主动提供
位置信息 GPS 经纬度、IP 定位 授权后自动获取
设备信息 型号、系统、浏览器 自动收集
使用日志 访问时间、页面、行为 自动收集
缓存数据 偏好设置、自定义城市 本地存储 (localStorage)

3信息的使用方式

我们收集的信息将用于以下目的：

  • 提供服务：根据您的位置提供天气预报、台风路径追踪等核心功能。
  • 改善体验：分析使用数据以优化界面设计、提升加载速度和功能体验。
  • 个性化推荐：根据您的自定义城市和偏好，提供定制化的内容展示。
  • 安全保障：检测异常行为、防范欺诈、维护服务的安全与稳定。
  • 问题排查：诊断技术问题、修复故障、回复您的反馈与咨询。
  • 服务通知：在必要时向您发送与服务相关的通知（如重大变更、安全提醒）。
我们不会将您的个人信息出售给任何第三方。所有信息的使用均严格限制在本政策所述范围内。

4信息的共享与披露

除以下情形外，我们不会向第三方共享您的个人信息：

  • 经您同意：在获得您明确同意后，我们可能会与第三方共享相关信息。
  • 服务提供商：我们可能委托可信的第三方服务提供商（如天气数据 API 提供方）处理数据，但仅限于提供服务所需的最小范围，且受保密义务约束。
  • 法律要求：在法律法规要求、政府主管部门命令或司法程序需要时，我们可能依法披露相关信息。
  • 安全保护：为保护我们、用户或公众的权利、财产或安全免受损害时。
  • 业务转让：在合并、收购或资产转让等交易中，相关信息可能作为资产转移，但我们将确保接收方继续遵守本政策。

5信息的存储与保护

5.1 存储位置与期限

  • 您的个人信息存储在位于中华人民共和国境内的服务器上。
  • 我们仅在为实现本政策所述目的所必需的最短期限内保留您的信息。
  • 超出保留期限后，我们将删除或匿名化处理您的个人信息。

5.2 安全措施

  • 传输加密：使用 HTTPS/TLS 协议对数据传输进行加密保护。
  • 存储加密：敏感数据（如密码）采用单向加密算法存储。
  • 访问控制：严格限制内部人员对个人信息的访问权限，实行最小权限原则。
  • 安全审计：定期进行安全评估和漏洞扫描，及时修复潜在风险。
  • 应急响应：建立数据安全事件应急预案，在发生安全事件时及时采取补救措施并通知您。
尽管我们采取了合理的安全措施，但互联网传输并非绝对安全。我们无法保证信息传输的百分之百安全性，请您知悉这一风险。

6Cookie 与相关技术

我们使用 Cookie、localStorage 及类似技术来记住您的偏好、改善服务体验：

  • 偏好存储：使用 localStorage 在您的设备本地存储自定义城市、主题偏好等设置，这些数据不会上传到服务器。
  • 缓存优化：缓存天气数据以实现离线浏览和更快的加载速度。
  • 分析统计：使用匿名分析工具了解服务的使用情况，以持续改进。

您可以通过浏览器设置管理或清除 Cookie 和本地存储数据。但请注意，禁用这些技术可能影响部分功能的正常使用。

8您的权利

根据适用的法律法规，您对个人信息享有以下权利：

  • 查询权：您有权查询我们持有的关于您的个人信息。
  • 更正权：当您发现我们持有的信息有误时，有权要求更正。
  • 删除权：在特定情形下，您有权要求我们删除您的个人信息。
  • 撤回同意权：您有权随时撤回此前给予的同意（如位置授权）。
  • 数据携带权：您有权以结构化、通用的格式获取您的个人信息副本。
  • 反对权：您有权反对我们出于特定目的处理您的信息。

如需行使上述权利，请通过本政策末尾的联系方式与我们沟通。我们将在收到请求后的合理期限内予以回复。

9未成年人保护

我们非常重视对未成年人个人信息的保护。我们的服务主要面向成年人，不针对 14 周岁以下的未成年人。

  • 如果您是 14 周岁以下的未成年人，请在使用我们的服务前获得监护人的同意。
  • 如果您是未成年人的监护人，发现您的被监护人在未经同意的情况下使用了我们的服务，请及时联系我们删除相关信息。
  • 我们不会主动收集未成年人的个人信息。如发现误收集，我们将尽快删除。

10政策更新

我们可能会不时更新本隐私政策以反映法律法规的变化、服务功能的调整或运营实践的改进。

  • 一般性变更：我们将更新页面顶部的"最近更新日期"。
  • 重大变更：涉及信息收集或使用方式的实质性变更时，我们将通过显著方式（如站内通知、弹窗提示）通知您。
  • 继续使用：政策更新后，您继续使用我们的服务即视为同意更新后的政策。

建议您定期查阅本页面以了解最新的隐私政策内容。
