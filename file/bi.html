隐私政策

币价雷达非常重视您的隐私。本政策详细说明我们如何收集、使用和保护您的数据。

最后更新日期：2026年8月1日

1引言

币价雷达（以下简称"本应用"）是一款用于查看加密货币实时行情和设置价格提醒的工具类应用。本应用仅供学生个人学习测试使用，不构成任何投资建议。

我们深知个人信息对您的重要性，因此制定了本隐私政策，以帮助您了解我们如何收集、使用、存储和保护您的数据。请您在使用本应用前，仔细阅读并充分理解本政策的全部内容。

简单来说：本应用不需要注册登录，不收集您的个人身份信息，所有数据仅存储在您的设备本地。

2我们收集的数据

本应用遵循"最小必要"原则，仅收集以下数据：

  • 您主动输入的数据：
    • 币种交易对符号（如 ETHUSDT、BTCUSDT）
    • 币种自定义名称（如"以太坊"）
    • 价格提醒设置（目标价格、触发方向）
    • 应用偏好设置（主题选择、涨跌颜色模式、置顶状态）
  • 自动获取的行情数据：
    • 通过 Binance 公开 API 获取的实时价格数据
    • 24小时价格涨跌幅数据
  • 设备本地存储的数据：
    • 上述所有数据均存储在您设备的 SharedPreferences 中，不会上传至任何服务器

我们不收集：您的姓名、手机号、邮箱、设备标识符（IMEI/IDFA）、位置信息、通讯录、相册、麦克风等任何个人敏感信息。

3数据使用方式

我们仅将收集的数据用于以下目的：

数据类型 使用目的 存储位置
币种符号与名称 显示您关注的币种列表 设备本地
实时价格数据 在行情页面展示最新价格与涨跌趋势 设备内存（不持久化）
价格提醒设置 在价格达到目标时发送系统通知 设备本地
24h涨跌幅 在币种卡片上显示日内涨跌百分比 设备本地
主题与偏好 记住您的主题选择和界面设置 设备本地

4第三方服务

本应用使用以下第三方服务来提供核心功能：

4.1 Binance API

  • 用途：获取加密货币的实时价格和24小时涨跌幅数据
  • 接口：api/v3/depth（深度行情）和 api/v3/ticker/24hr（24小时统计）
  • 传输内容：仅发送币种符号（如"ETHUSDT"），不包含任何个人信息
  • 隐私政策：请参阅 Binance 隐私政策

4.2 Android 系统服务

  • 通知服务：用于在价格达到目标时向您发送系统通知
  • WorkManager：用于在应用关闭后定期检查价格提醒（每15分钟）
  • 剪贴板：仅在您主动点击"作者联系"时复制QQ号到剪贴板

重要说明：本应用不集成任何广告SDK、统计分析SDK、推送服务SDK或第三方登录SDK。

5数据存储与安全

5.1 本地存储

您的所有数据（币种列表、提醒设置、偏好选项）均存储在您设备的 SharedPreferences 中，这是 Android 系统提供的本地轻量级存储方案。数据不会上传到任何云端服务器。

5.2 数据安全措施

  • 所有网络请求通过 HTTPS 加密传输
  • 不存储任何密码或敏感凭证
  • 不请求不必要的系统权限
  • 应用关闭后，内存中的价格数据会被清除，仅保留您设置的币种和提醒

5.3 数据删除

  • 您可以随时在应用内删除任何币种或提醒
  • 卸载应用后，所有本地数据将被自动清除
  • 您可以在系统设置中清除应用数据以删除所有存储的信息

6权限说明

本应用请求以下 Android 系统权限：

权限 用途 是否必须
互联网访问（INTERNET） 从 Binance API 获取实时价格 是
通知权限（POST_NOTIFICATIONS） 发送价格提醒通知 是（Android 13+）
前台服务（FOREGROUND_SERVICE） 保持价格监控在应用运行时不中断 是

承诺：本应用不请求摄像头、麦克风、位置、通讯录、相册等与核心功能无关的权限。

7后台运行说明

为了确保您不在应用内时仍能收到价格提醒，本应用使用以下机制：

  • 前台运行时：应用每 15 秒刷新一次价格数据，并通过前台服务保持监控状态
  • 应用关闭后：系统 WorkManager 每 15 分钟自动唤醒检查价格，无需保持应用运行
  • 后台检查时：仅获取有活跃提醒的币种价格，不获取无提醒的币种数据，减少网络请求

后台检查使用的是 Android 系统标准的 WorkManager 机制，不会额外消耗大量电量。

8儿童隐私

本应用不面向 13 岁以下的儿童。我们不会故意收集儿童的个人信息。如果您是儿童的监护人，发现您的孩子向我们提供了个人信息，请与我们联系，我们将及时删除相关信息。

9您的权利

根据相关法律法规，您享有以下权利：

  • 知情权：了解本应用如何收集和使用您的数据（即本政策）
  • 删除权：随时删除币种、提醒或清除应用数据
  • 卸载权：卸载应用即可完全清除所有本地数据
  • 拒绝权：拒绝授予通知权限（将无法收到价格提醒，但不影响行情查看）
